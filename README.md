# Supplier Trust Desk

Repository privat pentru Supplier Trust Desk: documentatia de produs, deciziile si cercetarea despre increderea in furnizori.

## Structura folderelor

```
supplier-trust-desk/
├── README.md                  # acest fisier
├── docs/
│   ├── icp/                   # profilul clientului ideal (firma, rolul care plateste, rolul care decide)
│   └── decisions/             # decizii cu data, motiv si alternative respinse
├── research/
│   ├── regulation/            # note despre cerintele de reglementare relevante pentru furnizori
│   └── sources/               # surse externe cu link si data accesului
└── product/                   # specificatii, cerinte si planuri de canale
```

## Documente existente

Niciunul inca. Documentatia se adauga in folderele de mai sus.

## Conventii

- Fiecare decizie importanta are un fisier in `docs/decisions/` cu format `AAAA-LL-ZZ-subiect.md`.
- Afirmatiile despre reglementare se leaga de o sursa din `research/sources/`.
- Estimarile proprii se marcheaza explicit ca estimari.
